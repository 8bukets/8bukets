# Palette's Journal - UX & Accessibility Learnings

This journal tracks critical UX and accessibility learnings.
Format: `## YYYY-MM-DD - [Title]` followed by `**Learning:**` and `**Action:**`.

## 2026-01-26 - [Navigation in Generated Reports]
**Learning:** Long, linear Markdown reports are difficult to navigate without a Table of Contents and "Back to Top" links. Standard GFM auto-anchors make this easy to implement without extra dependencies.
**Action:** Always include a ToC and navigation links when generating reports longer than one screen.
