## 2026-02-01 - [CLI & Report Micro-UX]
**Learning:** CLI tools are significantly more user-friendly when error messages include emojis (❌) and actionable tips (💡). Static Markdown reports are greatly enhanced by emojis and a Table of Contents for better scannability.
**Action:** Always include actionable tips in CLI error messages and use emojis/TOC in generated reports.
