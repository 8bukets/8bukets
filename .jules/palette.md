## 2026-01-28 - CLI Report Navigation
**Learning:** For CLI tools that generate static reports (like Markdown), the "user interface" is the report itself. Users find it difficult to navigate long text files without a Table of Contents and "Back to Top" links. Adding these simple navigation aids significantly improves the "readability UX" of the output.
**Action:** Always include a linked Table of Contents and section anchors in generated Markdown reports greater than one page.
