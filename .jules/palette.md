## 2026-01-11 - ASCII Bars for CLI Data Visualization
**Learning:** Text-based "charts" (using `█` and `░`) provide immediate visual context to numerical data in Markdown reports without requiring external image generation libraries. Users can instantly grasp relative scales (e.g., that one category dominates others) which a simple table of numbers fails to convey efficiently.
**Action:** When generating Markdown reports for CLI tools, always check if numerical data can be enhanced with simple ASCII visualizations to improve "at-a-glance" readability.
