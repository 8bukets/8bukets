## 2026-01-31 - Markdown as UI
**Learning:** For CLI tools where the primary output is a Markdown file, users treat the report itself as the "UI". Adding web-like navigation features (TOC, anchors, back-to-top links) and visual cues (emojis) significantly improves readability and user experience.
**Action:** When generating Markdown reports, always include a Table of Contents, explicit HTML anchors for stable linking, and "Back to Top" navigation aids. Use emojis in headers to improve visual scanning.
