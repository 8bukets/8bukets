## 2025-02-18 - [CLI Summary Box]
**Learning:** CLI tools often dump logs and exit, leaving the user to scroll back to find key metrics. A visual summary box at the end provides closure and highlights success metrics (like total items processed) without requiring a log dive.
**Action:** Use a "Summary Box" pattern for CLI scripts: a bordered text box with emojis and key-value pairs printed to stdout at the end of execution.
