## 2025-12-13 - [Markdown Navigation]
**Learning:** For command-line tools that generate static reports, treating Markdown as a UI by adding "Back to Top" links and a Table of Contents significantly improves the consumption experience of long-form data.
**Action:** Always include navigation aids in generated Markdown reports that exceed one screen length.
