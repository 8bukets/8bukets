## 2024-05-23 - CLI Visual Hierarchy
**Learning:** Users respond well to clear visual hierarchy in CLI tools. Using distinct colors for headers (Purple), info (Green), and errors (Red) significantly improves scannability. Emojis serve as effective visual anchors for different processing stages.
**Action:** Use the `Colors` class and emoji prefixes consistently for all future CLI agent outputs to maintain this hierarchy. The "Summary Box" pattern is particularly effective for final status.
