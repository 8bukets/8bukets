## 2026-01-11 - Markdown Data Visualization
**Learning:** ASCII bar charts (using `█` and `░`) significantly improve the glanceability of numerical data in Markdown reports.
**Action:** Use simple ASCII visualizations for "Top N" lists in text-based reports.

## 2026-01-11 - Managing Information Density
**Learning:** Large data tables in Markdown reports clutter the initial view.
**Action:** Use `<details>` and `<summary>` tags to collapse lists exceeding 10 items, preserving access without overwhelming the user.
