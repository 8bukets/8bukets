## 2026-01-31 - Navigation in Long Markdown Reports
**Learning:** Users struggle to navigate long scrolling reports. Adding a Table of Contents with explicit anchor tags significantly improves usability and 'web-like' feel, especially when using emojis in headers which can break auto-generated slugs.
**Action:** Always include a generated Table of Contents for reports longer than 2 screens, and use explicit HTML anchors for reliability.
