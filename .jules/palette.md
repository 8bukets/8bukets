## 2026-01-08 - Markdown Report Visual Hierarchy
**Learning:** Users respond well to "Progressive Disclosure" in static reports. Using HTML `<details>` tags for long lists (like trending topics) keeps the initial view clean while keeping data accessible. Combining this with a summary table creates a dashboard-like feel in a simple Markdown file.
**Action:** When generating long-form Markdown reports, always look for opportunities to use collapsible sections for detailed lists and summary tables for high-level metrics.
