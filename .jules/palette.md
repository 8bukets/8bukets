## 2026-01-07 - CLI/Data UX Enhancement
**Learning:** UX isn't limited to GUIs. Adding visual elements like ASCII charts and emojis to text-based reports significantly improves readability and "scan-ability" for backend tools.
**Action:** When working on CLI tools or data scripts, look for opportunities to visualize data using simple text characters (bars, tables, emojis) to make the output more human-friendly.
