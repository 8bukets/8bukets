## 2026-01-03 - CLI Report Readability
**Learning:** For command-line or script-based tools where the primary interface is a generated report, adding contextual data (like percentages alongside raw counts) significantly improves the "user experience" of data consumption. It transforms raw data into immediate insight.
**Action:** Always look for opportunities to compute and display derived metrics (%, delta, averages) in data reports to reduce cognitive load for the user.
