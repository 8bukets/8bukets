## 2026-01-31 - Markdown as UI
**Learning:** CLI tools often rely on generated Markdown files as their primary interface. Adding "web-like" features such as Table of Contents, anchor links, and emojis significantly improves the usability and "delight" of these static reports.
**Action:** Always verify generated Markdown reports for navigability and visual hierarchy. Use explicit HTML anchors for reliability.
