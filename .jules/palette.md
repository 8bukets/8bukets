## 2026-01-02 - CLI Visual Polish
**Learning:** Console output with high-volume logging (like a swarm of agents) is unreadable without visual hierarchy. Users miss errors because they blend with info logs.
**Action:** Use ANSI colors and emojis to create a visual scanning path. Errors should be red, headers bold/colored, and distinct agents should have consistent visual cues.
