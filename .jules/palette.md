## 2026-01-10 - Enhanced Markdown Report Readability
**Learning:** For data-heavy reports, ASCII progress bars provide an immediate visual understanding of relative magnitude that raw numbers lack. Collapsible sections (`<details>`) are essential for keeping reports clean when including long lists like authors.
**Action:** Always consider adding visual indicators (bars, emojis) and collapsible sections for detailed data in CLI-generated Markdown reports.
