## 2026-02-02 - Text-based Report UX
**Learning:** Even in CLI tools generating static files (Markdown), UX principles apply. Adding a Table of Contents and visual anchors (emojis) significantly improves the "readability" and "scannability" of the artifact, acting as a poor man's interactive UI.
**Action:** When working on data processing scripts, always consider the *consumer* of the output file. Add structure (TOC) and visual hierarchy (emojis/formatting) to raw text outputs.
