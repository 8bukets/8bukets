## 2025-12-24 - CLI Output as UX
**Learning:** UX isn't just about buttons and web pages. In a backend/CLI tool like this Python scraper, the "interface" is the generated report (Markdown). Improving readability here (dates, number formatting, percentages) significantly reduces cognitive load for the user analyzing the data.
**Action:** Always check the *output artifacts* of backend tools for UX opportunities. Use human-readable formats (e.g., "Oct 05, 2022") over machine formats ("2022-10-05") when presenting to humans.
