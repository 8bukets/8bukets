## 2026-01-31 - Markdown as a UI Surface
**Learning:** CLI tools often treat Markdown outputs as static text, but they are actually user interfaces. Adding TOCs, anchors, and navigation links transforms a simple data dump into a navigable dashboard, significantly improving the consumption experience without changing the underlying data.
**Action:** Always add navigation aids (TOC, Back to Top, Anchors) and visual hierarchy (Emojis) to generated Markdown reports that exceed one screen in length.
