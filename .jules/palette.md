## 2026-01-30 - Markdown Reports as UI
**Learning:** For CLI tools, the generated Markdown output is the primary user interface. Users interact with it like a webpage. Adding "web" features like a Table of Contents, emoji indicators, and "Back to Top" links significantly improves usability, especially for long reports.
**Action:** Always verify if a CLI tool generates reports and apply web UX patterns (navigation, hierarchy, visual anchors) to the output file.
