## 2024-10-26 - Markdown Reports as User Interfaces
**Learning:** CLI-generated Markdown reports often serve as the primary UI for users. Without navigation features like Tables of Contents and anchor links, long reports become difficult to traverse, reducing their usability and accessibility.
**Action:** Treat generated Markdown files as web pages. Always include a Table of Contents, explicit HTML anchors for deep linking, and "Back to Top" links to improve navigation for users and screen readers.
