## 2026-01-30 - Markdown as Primary UI
**Learning:** The generated Markdown report is the primary user interface for this CLI tool. Users will likely view this in a browser (via GitHub/GitLab) or a Markdown viewer. Without navigation, long reports are difficult to scan.
**Action:** Always include a Table of Contents (TOC), explicit anchor links (for cross-platform compatibility), and "Back to Top" links in generated Markdown reports that exceed one screen height. Use emojis in headers to improve visual scanning speed.
