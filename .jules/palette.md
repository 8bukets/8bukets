## 2026-01-12 - [ASCII Bar Charts in CLI Reports]
**Learning:** For command-line tools that generate Markdown reports, adding ASCII bar charts (using `█` and `░`) significantly improves the ability to scan data distributions without requiring external image generation libraries. This provides immediate visual value while maintaining zero dependencies and full text-based accessibility.
**Action:** When designing future text-based analytics tools, always include simple ASCII visualizations for frequency data to enhance the "glanceability" of the output.
