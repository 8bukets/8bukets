## 2025-12-29 - [CLI Output Readability]
**Learning:** In a multi-agent backend system, a wall of text logs can be overwhelming. Adding distinct emojis and colors for each agent (e.g., 🔍 for Researcher, 🧠 for Analyzer) significantly improves scanability and helps developers instantly recognize which part of the system is active without reading the text.
**Action:** When working on CLI tools with multiple concurrent or sequential processes, implement a custom logging formatter that visually distinguishes components using colors and icons.
