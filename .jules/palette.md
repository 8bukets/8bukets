## 2026-01-08 - [Markdown Report UX]
**Learning:** Collapsible `<details>` sections in Markdown are a powerful way to present verbose data without overwhelming the user, especially in static reports where interactivity is limited. Emojis serve as effective visual anchors for scanning sections.
**Action:** Apply this pattern to other report generators (like `orchestrator.py` or agent summaries) to handle long lists or debug data cleanly.
