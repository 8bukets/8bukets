# Palette's UX Journal

## 2024-10-25 - [CLI Output Readability]
**Learning:** Terminal output for long-running processes (like scrapers) is significantly harder to scan without visual anchors (colors/emojis), leading to "log blindness" where users miss errors.
**Action:** Implement ANSI color codes and consistent emoji prefixes for distinct log levels (Info, Success, Error) to create a visual hierarchy in CLI tools.
