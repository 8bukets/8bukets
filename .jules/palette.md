## 2026-01-25 - CLI Visual Hierarchy
**Learning:** CLI users benefit from visual landmarks (colors and emojis) just as web users do. Color-coded logs allow for faster scanning of status (green=good, red=bad), while emojis serve as section headers in a text-heavy stream.
**Action:** When building CLI tools, implement a custom logging formatter that supports ANSI colors and use consistent emoji indicators for major process steps.
