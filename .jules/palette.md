## 2026-01-30 - Added Navigation to Daily Reports
**Learning:** Users engaging with long Markdown reports benefit significantly from a Table of Contents and "Back to Top" links, as scrolling through raw text files can be disorienting. Explicit HTML anchors (`<a name="..."></a>`) are more reliable than implicit Markdown header anchors across different viewers.
**Action:** When generating automated reports, always structure them with a TOC and consistent navigation markers to improve consumption speed.
