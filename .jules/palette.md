## 2025-10-26 - Markdown Reports as UX
**Learning:** For CLI tools without a GUI, the output artifact (e.g., Markdown report) IS the user interface. Enhancing it with visual hierarchy (emojis), navigation (TOC, Back to Top), and clear formatting significantly improves the "readability UX" for the end user.
**Action:** Always treat generated reports as first-class UI components. Apply web design principles (hierarchy, navigation, whitespace) to static documents.
