## 2024-05-23 - CLI Polish as UX
**Learning:** In a repo without a web frontend, the CLI *is* the user interface. Users notice and appreciate when CLI tools respect their attention by using colors for status (Green=Good, Red=Bad) and summary boxes to verify results at a glance.
**Action:** Always check if a CLI tool has formatted output. If not, adding `colors.py` and a summary table is a high-value, low-effort "micro-UX" win.
