## 2026-02-01 - Generated Markdown Reports as Dashboards
**Learning:** Even static Markdown reports benefit significantly from web-like navigation (TOC, anchor links, "Back to Top"). Users treat these reports as dashboards, not just text files. Emojis in headers serve as visual anchors, making scanning much faster.
**Action:** Always add a Table of Contents and "Back to Top" links to generated reports longer than one screen height. Use consistent emojis for section types.
