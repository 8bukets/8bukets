## 2024-03-24 - CLI Output Coloring
**Learning:** Adding colored output to CLI tools significantly improves readability and user experience by visually distinguishing between information, warnings, and errors. This can be done without external dependencies using ANSI escape codes and a custom `logging.Formatter`.
**Action:** When working on CLI tools, look for opportunities to enhance the output with color coding to provide immediate visual feedback to the user. Ensure to handle `__pycache__` and data files correctly in `.gitignore` to avoid polluting the repository.
