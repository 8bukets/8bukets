# Palette's Journal

## 2024-05-22 - CLI Summary Box Pattern
**Learning:** For CLI tools without rich UI libraries, a simple "Summary Box" using raw ANSI escape codes provides high-value closure to the user interaction. It separates the "result" from the "process logs".
**Action:** Use the `Colors` class pattern and `print_summary` method for all CLI scripts in this project to maintain consistency and delight.
