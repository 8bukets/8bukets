## 2026-01-22 - Markdown Report Navigation
**Learning:** For long generated Markdown reports that serve as a primary UI, users struggle with scrolling. Adding a Table of Contents (TOC) with deep links and "Back to Top" anchors significantly improves navigation.
**Action:** When generating Markdown reports, always include a TOC at the top and explicit HTML anchors (e.g., `<a id="section"></a>`) in headers to ensure reliable deep linking, especially when using emojis.
