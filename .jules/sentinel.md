## 2026-01-22 - Path Traversal in CLI Output Arguments
**Vulnerability:** The `scraper.py` and `analytics.py` scripts allowed users to specify arbitrary file paths for output (and input in analytics), enabling writing to files outside the working directory (e.g., `/tmp/pwned.json`). This could lead to arbitrary file overwrite or reading sensitive files if the script runs with elevated privileges or if the user is tricked.
**Learning:** CLI tools often trust user input for file paths, assuming the user knows what they are doing. However, in a secure environment or when wrapped by automation, this can be a vector for attack. Explicitly validating that paths are contained within the expected directory (CWD) prevents this class of vulnerability.
**Prevention:** Implemented a `validate_path` function that resolves paths to absolute paths and checks if they share a common path with the current working directory (`os.getcwd()`). Applied this validation to all file I/O arguments in the CLI entry points.
