## 2024-05-23 - [CSV Formula Injection in Scraper Output]
**Vulnerability:** The scraper was writing raw text fields (like Title, Author) directly to a CSV file. If these fields started with characters like `=`, `+`, `-`, or `@`, spreadsheet software (e.g., Excel) would interpret them as formulas. This could lead to Formula Injection (CSV Injection), potentially allowing attackers to execute commands or exfiltrate data from the analyst's machine.
**Learning:** Data extracted from external websites should never be trusted. Even "passive" formats like CSV can be vectors for attack if the consuming application (Excel) interprets the data as code/formulas.
**Prevention:** Implemented a sanitization function `_sanitize_csv_field` that checks if a string starts with a formula trigger character. If it does, it prepends a single quote (`'`) to force the spreadsheet software to treat the content as literal text. This sanitization is applied to all fields before writing to the CSV.
