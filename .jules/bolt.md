## 2026-01-02 - [SoupStrainer Class Matching Behavior]
**Learning:** `SoupStrainer`'s `class_` argument performs an *exact string match* against the tag's class attribute, whereas `BeautifulSoup.find_all` treats `class_` as a "contains token" check (checking if the value is in the class list). For example, `SoupStrainer('div', class_='foo')` will NOT match `<div class="foo bar">`, but `soup.find_all('div', class_='foo')` WILL match it. To match partial classes with `SoupStrainer`, you must use a compiled regex (e.g., `re.compile(r'\bfoo\b')`) or a function.
**Action:** When optimizing parsing with `SoupStrainer`, always check if the target tags have multiple classes. If so, use regex instead of a string literal for the `class_` argument to avoid silently filtering out valid elements.
