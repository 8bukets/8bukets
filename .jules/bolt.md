## 2024-01-11 - SoupStrainer with BeautifulSoup for Partial Parsing
**Learning:** `SoupStrainer` is an effective way to optimize `BeautifulSoup` parsing by only parsing specific parts of the document. However, when filtering by class, `SoupStrainer` uses exact string matching for the `class` attribute (unlike `find_all` which splits the class attribute by spaces). To correctly match elements with multiple classes using `SoupStrainer` (e.g. `<article class="post type-post ...">`), one must use a regex (e.g. `re.compile(r'\bpost\b')`) instead of a simple string or `class_` keyword argument which might imply exact match or list containment behavior that `SoupStrainer` implements differently or strictly during the initial parse phase.

**Action:** When using `SoupStrainer` to optimize parsing performance on elements with multiple classes, prefer using `re.compile` to match the desired class name within the attribute string, rather than relying on standard `find_all` style class matching.
