## 2024-05-22 - SoupStrainer Attribute Matching Specificity
**Learning:** `SoupStrainer` with a `class_` argument checks for strict presence of the exact string value in the class list when using `html.parser`, or exact string match of the attribute value depending on how it's invoked. It can be fragile if the class attribute contains multiple classes and the strainer logic expects partial matches differently than `find_all`.
**Action:** When using `SoupStrainer` for robustness, prefer straining by Tag name only (e.g. `SoupStrainer('article')`) to reduce the parsing scope significantly, and then apply specific attribute filters using `find_all` on the reduced tree. This offers the best balance of performance (skipping non-relevant tags) and safety (correctly handling complex attributes).
