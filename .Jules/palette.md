## 2026-01-16 - CLI UX Patterns
**Learning:** In CLI-only environments (no web frontend), UX = DX (Developer Experience). Visual feedback using ANSI colors and emojis significantly improves scannability of logs compared to plain text.
**Action:** When working on CLI tools, always implement a lightweight logging utility with visual indicators (✅, ❌, 🚀) early in the process.
