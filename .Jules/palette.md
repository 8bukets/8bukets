## 2026-01-08 - Markdown Report Visual Hierarchy
**Learning:** Users can digest information significantly faster when key metrics are summarized in a table at the top of the report. This prevents "scrolling fatigue" where critical status information (like DB health or Active Campaigns) is buried in the document.
**Action:** In future report generation tasks, always include an "Executive Summary" table at the beginning of the Markdown document that aggregates high-level status indicators (using emojis for quick scanning).
