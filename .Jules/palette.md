## 2026-01-19 - CLI Report UX
**Learning:** Automated Markdown reports often lack navigability. Adding a Table of Contents with explicit HTML anchors (`<a name="...">`) and "Back to Top" links transforms a flat log into a usable document. Emojis in headers improve scannability.
**Action:** When generating Markdown reports, always include a TOC and explicit anchors for key sections to ensure consistent navigation across different Markdown renderers.
