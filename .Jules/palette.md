## 2025-12-25 - Structure in Text-Based Interfaces
**Learning:** Even in text-only interfaces like Markdown reports, standard UX principles apply. Adding a Table of Contents and "Back to Top" links significantly reduces cognitive load and scroll fatigue for users reviewing long automated reports. Visual hierarchy (emoji indicators, badges) helps users scan for status immediately.
**Action:** When designing text outputs (logs, reports, emails), always consider navigation and "at a glance" status indicators. Treat the output as a read-only UI.
