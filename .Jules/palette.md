## 2026-01-13 - [ASCII Charts in Markdown Reports]
**Learning:** Adding simple visual elements like ASCII bar charts to text-based reports significantly improves scannability and "delight" without requiring complex frontend libraries. It transforms a wall of data into an intuitive visualization.
**Action:** Always look for opportunities to visualize numerical data in CLI outputs or generated Markdown using ASCII/Unicode characters (e.g., `█`, `░`, `▒`).
