# Antigravity Integration Rules

1. **Autonomous Sync**: All system evolutions must be synchronized with the Antigravity platform via the CollaborationAgent.
2. **Metadata Export**: System version, performance metrics (Sigma status), and stakeholder updates must be exported in every cycle.
3. **Collaborative Workflow**: The system must prioritize tasks that enhance multi-agent collaboration as defined in the Jules-Antigravity bridge.
4. **Security**: All exports to the platform must redaction PII as per system standards.
