# Copy Guide

## Goal

Provide clean starter copy for the homepage, calls to action, onboarding, and launch messaging.

## Positioning

The product should feel:

- trust-first
- useful
- structured
- credible

Avoid sounding like:

- a hype landing page
- a generic directory
- a spammy comparison site

## Short Product Description

Software Review Platform helps people discover better software through structured reviews, transparent moderation, and clearer trust signals.

## Homepage Headline Options

### Option 1

Discover software through more credible reviews.

### Option 2

Find better tools with structured, trust-focused software reviews.

### Option 3

Software reviews built for clarity, not noise.

## Homepage Supporting Copy

Option:

Browse software profiles, read moderated reviews, and explore tools through a platform designed to make software decisions more informed.

## CTA Options

### Browse

- Browse software reviews
- Explore software
- Discover tools

### Contribute

- Write a review
- Share your experience
- Add your review

### Trust

- See how moderation works
- Learn how reviews are reviewed

## Onboarding Copy

### Registration

Create an account to write reviews, rate software, and join a more credible review community.

### Review Submission

Share what the software was useful for, what worked well, and where it fell short.

### Moderation Notice

Reviews are moderated before publication to help keep the platform useful and trustworthy.

## Admin Copy

### Moderation Queue

Review pending submissions and approve the content that adds real value to software buyers.

## Existing Site CTA Copy

Use these on `software-online-review.com` to bridge traffic into the app:

- Browse software reviews
- Explore trusted software insights
- Write a review
- Visit the review platform

## Soft Launch Announcement Copy

Short version:

We are launching a new review experience for software discovery, built around structured reviews, moderation, and clearer trust signals.

## Messaging Rules

- keep copy direct
- avoid exaggerated claims
- emphasize clarity and trust
- mention moderation as a benefit, not a barrier
- keep first-launch messaging simple
