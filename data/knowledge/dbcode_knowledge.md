## Overview

DBCode is a modern database client for VS Code, Cursor, and Windsurf - with first-class Copilot and MCP integration. Browse schemas, edit data, visualize queries, and manage 50+ databases without leaving your editor. SQL Notebooks, auto-generated ER diagrams, and secure report sharing.

## Supported Databases

PostgreSQL, MySQL, SQL Server, SQLite, Oracle, MongoDB, Redis, DuckDB, Snowflake, BigQuery, Databricks, ClickHouse, Cassandra, Elasticsearch, Neo4j, Firebase, DynamoDB, MariaDB, and 50+ more engines including warehouses, lakehouses, and file formats.

## Key Features

- Data Viewing & Editing: VS Code database GUI - filter, sort, group, and edit data directly.
- Copilot Integration: Natural language to SQL queries.
- Entity Relationship Diagrams: Auto-generated from live schema. Export as PDF, HTML, or PNG.
- Foreign Key Navigation: Navigate relationships without writing JOINs.
- SQL Editor: Full editor with intellisense, autocomplete, and inline signature help.
- Secure Report Sharing: Encrypted database report sharing.
- Database Notebooks: SQL and Python cells in VS Code Notebooks with Jupyter kernel integration.
- Execution Plans: Visualize EXPLAIN and ANALYZE output as interactive node graphs.
